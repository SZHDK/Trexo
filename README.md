# Trexo

Loo kaasaegne eestikeelne haljastusfirma veebileht. Lehel peab olema hinnapakkumise küsimise vorm (nimi, e-post, telefoninumber, töö kirjeldus), tehtud tööde fotogalerii/portfoolio, pakutavate teenuste ülevaade ja kontaktandmed.
